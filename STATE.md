# STATE — Warcraft TD

## Текущее состояние

- Unity 6000.3.24f1, URP 17.3.0, Android landscape; Unity Hub и Android-модули установлены, лицензия Personal активна.
- Проект: `WarcraftTD/`. Инструкция ИИ: `AGENTS.md`. Карта источников: `outputs/Warcraft_TD_Project_Index.md`.
- Знания разделены: общее видение — `Warcraft_TD_Overview.md`, механики — `Warcraft_TD_Design.md`, сюжет — `Warcraft_TD_Story.md`, разработка — `Warcraft_TD_Development.md`, архитектура — `Warcraft_TD_Modules.md`.
- Первая миссия работает как вертикальный срез: карта А→Б, подготовка 60 секунд, лучники, баллисты, золото, динамический маршрут, люди-зомби трёх типов брони, база, финальный прорыв, паладин и открытие каменных стен.
- Реализованы отдельные заготовки M01 `FirstMissionFlow`, M03 `GridPathfinder`, M05 `CombatRules`, M20 `PrototypeBuilder`. Остальные runtime-роли пока частично собраны в `PrototypeGame`.
- Утверждён визуальный вход: видео движка → видео/заглушка компании → ключевой арт → при первом запуске вступительная кат-сцена о нападении нежити и Рыцаре Света. Реализация и финальные медиаматериалы ещё не добавлены.
- Рыцарь Света и человеческий король — один и тот же центральный персонаж сюжетной арки.
- Утверждены биомы пяти кампаний: человеческие луга и малые леса; великий лес эльфов; красно-бурые скалистые земли орков с геотермальной активностью; болота, пепелища и снежные горы Земли мёртвых; огненный хаос ада.
- Местность влияет на бой и путь: высота увеличивает дальность башен; подъём, спуск, каменная дорога, болото и снежные горы меняют скорость; горы непроходимы; гейзеры и лава наносят природный урон. Числа ещё не сбалансированы.
- Карты получают живое окружение по биому: камни, деревья, траву и птиц. В эльфийском лесу частями и без интерфейсных подсказок появляется божественный олень — скрытый наблюдатель за повествованием.
- Первый релиз определён как завершённая кампания людей; остальные кампании, метаигра, пользовательский редактор, серверный рейтинг, модерация и батлпасс планируются обновлениями после релиза.
- Игра проектируется мультиплатформенной: первый магазин — Google Play для Android, следующее направление — только iPhone; iPad, macOS и остальные Apple-платформы пока исключены. Проект ведёт один разработчик. Баланс должен редактироваться через отдельный GUI M22 и конфигурации, а не через правку кода.
- Первый релиз поддерживает Android 7.1 / API 25 и новее; Android 7.0 и более старые версии исключены. Настройка Unity уже соответствует этому решению.
- Общая художественная дуга постепенно ведёт от светлого человеческого начала к предельному мраку, хаосу и психологическому давлению ада.
- Производство ведётся без найма: бесплатные лицензированные ассеты перерабатываются под стиль игры, интерфейс рисует пользователь и развивает по релизам, музыка создаётся ИИ, ранняя озвучка идёт через указанный Telegram-сервис после проверки прав.
- Онлайн-этап будет работать на собственном модульном backend и базе данных; UGS не является основным серверным решением.
- Серверный стек утверждён: C#/.NET 10 LTS, ASP.NET Core, EF Core/Npgsql, PostgreSQL 18, Docker Compose и Caddy на Ubuntu Server 26.04 LTS внутри VMware Workstation; хост — компьютер пользователя с белым IP.
- PostgreSQL хранит структурированные данные, JSON карт и небольшие бинарные данные; большие видео лежат в постоянном файловом каталоге, а их метаданные и хеши — в PostgreSQL.
- Google/Apple подтверждают платформенную личность, после чего backend связывает её с собственным неизменяемым `PlayerID`; прогресс и покупки хранятся по внутреннему ID, допускающему несколько платформенных привязок.
- Локальный Git создан в корне проекта; `main` отслеживает `origin/main` в `https://github.com/Exzertist/warcraft-td.git`, исходная точка — `9d961c3`, текущая версия — `v0.1.1-android`.

## Риски и правила

- `PrototypeGame` перегружен: M02, M04, M07–M10 и M16 нужно извлекать по порядку из карты модулей.
- Не раскрывать игрокам скрытые способности огненного и земляного драконов.
- Временные числа прототипа не считать утверждённым балансом без записи в дизайн-документ.
- Сервер должен быть авторитетным для рейтинга, модерации, платных наград и сезонного прогресса.
- Бесплатные материалы, ИИ-музыка и голосовые записи нельзя выпускать без сохранённого источника и подтверждённых прав; извлечённые ассеты Warcraft не использовать без разрешения правообладателя.
- Домашний сервер создаёт риски отключения питания/интернета, отказа диска и внешних атак; PostgreSQL нельзя публиковать наружу, а база и медиа требуют внешних резервных копий.
